Masuk ke Dashboard

Dashboard ini menyimpan perubahan langsung ke repositori GitHub kamu. Vercel otomatis membangun ulang situs setelahnya — biasanya selesai dalam 1–2 menit.

Soal keamanan token

Token GitHub kamu disimpan di browser ini saja (localStorage), tidak pernah dikirim ke server mana pun selain GitHub. Tapi konsekuensinya nyata:

  • Jangan pakai dashboard ini di komputer umum atau bersama.
  • Buat token fine-grained yang hanya bisa mengakses repo sementaun-site, jangan token classic yang bisa akses semua repo.
  • Kalau tokennya bocor, orang bisa mengubah isi situs ini — bukan akun GitHub kamu secara keseluruhan.
  • Kamu bisa cabut kapan saja di GitHub → Settings → Developer settings.
Cara membuat token (sekali saja)
  1. Buka github.com/settings/personal-access-tokens/new
  2. Token name: bebas, misalnya Dashboard Sementaun
  3. Expiration: pilih sesuai selera (90 hari aman)
  4. Repository access → Only select repositories → pilih sementaun-site
  5. Permissions → Repository permissions → Contents → set ke Read and write
  6. Klik Generate token, salin, lalu tempel di bawah
